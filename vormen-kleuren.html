Basisvormen in P5.js

In P5.js kunnen we verschillende basisvormen tekenen:

  • ellipse() - voor cirkels en ovalen
  • rect() - voor rechthoeken en vierkanten
  • triangle() - voor driehoeken
  • line() - voor lijnen

Voorbeeld: Vormen en Kleuren

Code Voorbeeld

// Basisvormen tekenen
ellipse(100, 100, 50, 50);  // cirkel
rect(200, 75, 50, 50);      // vierkant
triangle(300, 100, 275, 150, 325, 150);  // driehoek

// Kleuren instellen
fill(255, 0, 0);    // rood
stroke(0);          // zwarte rand
strokeWeight(2);    // rand dikte
